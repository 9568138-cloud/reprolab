# 演示视频分镜（5–8 分钟 · 含 ≥2 分钟 AI 协同复现）

> 官方要求：5–8 分钟；**至少 2 分钟展示 AI 协同复现过程**；链接须公开可访问（B 站 / 抖音）。
> 目标：让评委在 90 秒内看懂「一句话 → 可审阅计划 → 每步留痕 → 逐位复现」，再用 2 分钟看懂「AI 怎么被约束、怎么迭代」。

---

## 一、录制前 5 分钟准备

| 项 | 做法 |
| :-- | :-- |
| 窗口 | 浏览器全屏 1920×1080，缩放 125%；关掉所有通知（微信/QQ/邮件） |
| 终端 | 单独一个窗口，字体调到 18px，只留 `reprolab` 目录 |
| 隐私 | 桌面不放私人文件；终端路径不要出现用户名以外的个人信息；录制里不要出现 API Key |
| 预跑 | 先跑一遍「一键演示」确认 8 秒能跑完；再手动跑一遍热手 |
| 素材 | `work/reprolab/docs/` 四张界面图、`prompts/screenshots/` 四张会话截图备用（放第二个屏幕） |
| 录屏 | OBS / Win+G，只录浏览器窗口 + 终端窗口；分辨率 1080p，30fps |

## 二、分镜表

### 第 1 段｜痛点与定位（0:00–0:45）

| 画面 | 操作 | 口播要点 |
| :-- | :-- | :-- |
| 空白浏览器 → 打开 `http://127.0.0.1:5173` | 首页滚动一次 | 「做实验、写报告的人都有个共同痛点：结论和数据对不上，别人复现不出来。 ReproLab 把一句话变成一份可审阅的计划，每条结论都能点回它的计算步骤。」 |
| 首页（data 接入区） | 鼠标划过 dropzone | 「零依赖纯前端，数据不出本机，断网也能跑。」 |

### 第 2 段｜完整闭环（0:45–2:15）

| 画面 | 操作 | 口播要点 |
| :-- | :-- | :-- |
| 点「▶ 一键演示」 | 全流程自动 | 「我点一键演示，它会把真实流程走一遍，方便评委 30 秒看清结构。」 |
| 停在第 03 步计划卡 | 暂停 3 秒 | 「注意这一步：AI 只能输出这 6 个算子的 JSON，第 2 步是删数据，属于破坏性操作，执行按钮是灰的——必须我勾选确认。」 |
| 展开「查看计划 DSL」 | 点开 → 再收起 | 「这就是 AI 的全部产出，一屏能读完，没有一句话是模型直接执行的代码。」 |
| 勾选确认 → 执行 | 点执行 | 「执行在浏览器内，每一步都留输入/输出哈希和耗时。」 |

### 第 3 段｜结论溯源（2:15–3:00）

| 画面 | 操作 | 口播要点 |
| :-- | :-- | :-- |
| 结论卡 | 鼠标停在 `r = -0.9635` 徽章上 | 「r 不是一个写死的字符串，它绑在 s3 的输出字段上；字段不存在，页面直接拒绝渲染。」 |
| 点徽章 | 时间轴对应步骤高亮 | 「点一下，就跳到算出这个数的步骤。」 |
| 滚到图 | 停留 3 秒 | 「图上两个红圈就是被剔掉的 2 行原始数据，第 22、43 行——删了什么，看得见。」 |

### 第 4 段｜复现（3:00–3:40）

| 画面 | 操作 | 口播要点 |
| :-- | :-- | :-- |
| 点「重跑一致性校验」 | 等结果 | 「同一数据 + 同一计划，重跑两次产物哈希逐位相同。」 |
| 点「导出复现包」 | 等下载 | 「导出的是数据、计划、执行记录、报告，还有一份自带校验脚本。」 |
| 切终端 | `cd 下载目录 && unzip -o reprolab-*.zip -d check && cd check && node verify.mjs` | 「评委不需要打开 ReproLab，一条命令就能验：数据哈希、产物指纹、算子白名单。」 |
| 终端（可选加戏） | 改 `run.json` 里一个数字 → 再跑 `node verify.mjs` | 「改任何一个数字，它立刻 FAIL 并返回退出码 1。」 |

### 第 5 段｜AI 协同复现（3:40–6:10，**≥2 分钟**）

这一段是评分重点：不是演「AI 帮我写代码」，而是演「我怎么约束它、怎么发现它错、怎么改回来」。

| 画面 | 操作 | 口播要点 |
| :-- | :-- | :-- |
| 全屏展示 `prompts/screenshots/` 四张会话截图 | 一张张过 | 「需求、方案、建仓这三段发生在 CherryStudio，AI 给的是作战手册，我按它执行——这是原始会话，没改过。」 |
| 全屏展示 `prompts/README.md` | 滚到 iter-01 | 「真正的代码迭代有 8 轮，每轮一个 commit，记录 AI 产出、我发现了什么问题、怎么改的。」 |
| 讲 iter-01 的 bug | 高亮那段文字 | 「第一版解析器把 CSV 里的 `#` 注释行当表头，测试直接挂。我没有让它自己修，而是先把约束写清楚：注释行必须跳过，示例数据用 Node 重新生成——因为用 PowerShell 写中文文件会被按 GBK 读。」 |
| 打开 `tests/kernel.test.mjs` | 滚到那条测试 | 「问题修完立刻固化成测试，13 条测试现在是这条链的护栏。」 |
| 展示 `src/kernel/index.js` 里的 `canonicalArtifact` | 高亮函数 | 「复现的口径只有一处实现：界面重跑、导出包、第三方校验都用它，避免‘两套哈希对不上’。」 |
| 讲 iter-07 的翻车修复 | 展示 `src/export/package.js` 里的 verify 脚本 | 「第一版导出的校验脚本引用了包外文件，评委解压后根本跑不起来——这是我自测时发现的，重写成零依赖自包含，并且加了篡改检测。」 |

### 第 6 段｜边界与收尾（6:10–6:50）

| 画面 | 操作 | 口播要点 |
| :-- | :-- | :-- |
| README 的「已知边界」 | 停留 | 「我不吹它能做一切：支持 5 万行以内、6 个算子、单文件单用户；跨 CPU 浮点差异没验证。边界写清楚，比夸大更可信。」 |
| 结尾定格到首页 | 慢滚 | 「溯真 ReproLab：结论有出处，过程可复现。」 |
